# Имперский датаслейт

Готовое одностраничное приложение для Imperium Maledictum. Оно содержит досье агента, боевой устав, арсенал и окно развития персонажа.

## Как загрузить на GitHub

1. Создайте на GitHub новый пустой репозиторий.
2. Распакуйте архив и загрузите **содержимое** папки в корень репозитория. Файл `package.json` должен лежать в корне.
3. Убедитесь, что основной веткой репозитория является `main`.
4. Откройте `Settings` → `Pages`.
5. В разделе `Build and deployment` выберите источник `GitHub Actions`.
6. Перейдите во вкладку `Actions` и дождитесь завершения процесса `Deploy Imperium Dataslate`.

После этого адрес приложения появится в `Settings` → `Pages`. При каждом новом сохранении в ветку `main` GitHub будет автоматически пересобирать приложение.

## Запуск на компьютере

Потребуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Команда для создания готовой статической сборки:

```bash
npm run build
```

Результат появится в папке `dist`.

## Структура проекта

- `src/App.tsx` — разметка и логика интерфейса;
- `src/styles.css` — оформление и адаптивная верстка;
- `src/assets` — декоративные изображения интерфейса;
- `public` — иконка и изображение для карточки ссылки;
- `.github/workflows/deploy-pages.yml` — автоматическая публикация GitHub Pages;
- `dist` — уже собранная версия приложения.

Сейчас данные персонажа демонстрационные и хранятся внутри `src/App.tsx`. Состояние боевой сцены, боезапас и покупки опыта работают в пределах открытой страницы, но после перезагрузки сбрасываются. Постоянное сохранение можно добавить следующим этапом.
