# Имперский датаслейт

Интерактивное одностраничное приложение для **Imperium Maledictum**, подготовленное для публикации через GitHub Pages.

## Что уже работает

- мобильный лист персонажа, повторяющий структуру обеих страниц официального бланка на стр. 363–364;
- автоматические максимум ран, критические раны, инициатива, предел переносимого веса и варп-порог;
- полный перечень 20 умений и 77 специализаций из книги;
- нажатие на умение открывает справочное окно и предлагает выбрать базовое умение или одну из изученных специализаций;
- в справочном окне показаны дословные описания умения и выбранной специализации со страниц 93–101, а также встречное умение, когда книга указывает его прямо;
- бросков костей внутри приложения нет: оно служит листом персонажа и подсказкой для игры за столом;
- база всех 93 талантов с требованиями, ценой, страницей и дословным текстом из книги;
- развитие характеристик, умений, специализаций и талантов с автоматическим учётом полученного, потраченного и свободного опыта;
- каталог из 175 записей главы «Арсенал»: оружие, боеприпасы, гранаты и взрывчатка, улучшения оружия, броня, защитные поля, носимое снаряжение, инструменты и аугметика;
- добавление вещей в инвентарь, автоматический подсчёт веса и немедленное отображение оружия, брони и снаряжения в листе персонажа;
- кликабельные списки талантов и снаряжения непосредственно в листе персонажа;
- отдельный полноэкранный паспорт каждого холодного и стрелкового оружия с уникальным масштабируемым техночертежом, характеристиками и кликабельными свойствами;
- отдельное меню монтажа всех 10 улучшений оружия с учётом совместимости, количества экземпляров в инвентаре, одной ячейки прицела и одной ячейки боевого улучшения;
- раскрывающийся справочник 22 боевых действий и всех 13 состояний персонажа с полным текстом книги и страницами источника;
- справочник поля боя и окружения со всеми 20 разделами правил на стр. 200–206;
- полный справочник из 60 результатов критических ран головы, руки, торса и ноги со стр. 358–361;
- добавление критической раны в профиль с выбором левой или правой конечности и одновременным отражением в официальных строках листа;
- кликабельные номера страниц: при наличии снимка открывается страница книги, иначе — встроенная страница с точным текстом соответствующего правила;
- выделение жирным всех проверок и характеристик внутри длинных правил;
- автоматическое сохранение данных персонажа в браузере на текущем устройстве.

Источник данных: русская книга правил, версия перевода **1.01**. Длинные описания скрыты в справочных окнах и открываются нажатием на умение, специализацию, талант, предмет, действие или состояние.

## Публикация на GitHub Pages

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория. Файлы `index.html`, `package.json` и папка `assets` должны оказаться в корне, а не во вложенной папке.
3. Убедитесь, что основная ветка называется `main`.
4. Откройте `Settings` → `Pages`.
5. В `Build and deployment` выберите `Deploy from a branch`.
6. Выберите ветку `main`, папку `/(root)` и нажмите `Save`.

Адрес опубликованного приложения появится в `Settings` → `Pages`. Корень архива уже содержит готовую статическую сборку, поэтому GitHub не должен запускать исходный TypeScript-файл в браузере.

Также оставлен процесс `Deploy Imperium Dataslate` для варианта `GitHub Actions`. Оба способа публикации используют относительные пути и работают в подпапке с любым названием репозитория.

## Запуск на компьютере

Потребуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Терминал покажет локальный адрес. Для контрольной статической сборки:

```bash
npm run build:pages
npm run preview
```

Команда `npm run build:pages` одновременно обновляет папку `dist` и готовые файлы в корне репозитория. Исходный входной файл проекта называется `index.source.html`; опубликованный `index.html` менять вручную не требуется.

## Где находятся данные и логика

- `src/data/rules.ts` — единая база правил;
- `src/data/skillRules.ts` — дословные описания всех умений и специализаций, ссылки на встречные проверки;
- `src/data/talentRules.ts` и `src/data/talents-raw.txt` — дословные тексты всех талантов;
- `src/data/environmentRules.ts` — правила поля боя и окружения;
- `src/data/injuryRules.ts` — все таблицы критических ран;
- `src/components/WeaponBlueprint.tsx` — уникальные SVG-чертежи оружия;
- `src/App.tsx` — состояние персонажа, расчёты и интерфейс;
- `src/styles.css` — техноготическое оформление;
- `index.source.html` — входной файл исходного проекта;
- `index.html` и `assets/` — готовая версия для публикации из корня ветки;
- `.github/workflows/deploy-pages.yml` — автоматическая публикация GitHub Pages.

PDF книги не требуется посетителю сайта: справочники уже встроены в сборку, поэтому приложение работает автономно после публикации.
